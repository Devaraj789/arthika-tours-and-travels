# Arthika Tours and Travels – Website

## Files Structure
```
arthika-tours/
├── index.html          ← Main homepage (royalcabs style)
├── style.css           ← All styles
├── script.js           ← Slider + WhatsApp form + mobile nav
├── .replit             ← Replit config (auto-runs server)
└── pages/
    ├── tour-packages.html
    ├── destinations.html   (add manually)
    ├── car-rental.html     (add manually)
    ├── rameswaram-packages.html (add manually)
    ├── hotels.html         (add manually)
    └── about.html          (add manually)
```

## Option 1 – Replit (Live Preview instantly)
1. Go to replit.com → Create Account (Free)
2. Click "+ Create Repl" → "Import from ZIP"
3. Upload arthika-tours.zip
4. Click Run → Site goes live at: https://arthika-tours.username.repl.co

## Option 2 – GitHub Pages (100% Free, Professional)
1. github.com → Create Account
2. New Repository → "arthika-tours-and-travels" → Public
3. Upload all files (drag & drop)
4. Settings → Pages → Branch: main → Save
5. Live at: https://username.github.io/arthika-tours-and-travels
